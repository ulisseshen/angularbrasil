# Utilitários de teste do Zone.js {#zonejs-testing-utilities}

Este guia descreve os utilitários de teste usados principalmente para gerenciar e controlar tarefas assíncronas em testes unitários. Esses utilitários são, essencialmente, os utilitários de relógio simulado específicos do Zone.js, especialmente relevantes para controlar o fluxo de operações assíncronas dentro dos testes.

Para os utilitários gerais de teste do Angular, incluindo o `TestBed` e o `ComponentFixture`, veja o guia [APIs utilitárias de teste](guide/testing/utility-apis).

Aqui está um resumo das funções específicas do Zone.js:

| Função                 | Detalhes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| :--------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `waitForAsync`         | Rastreia tarefas assíncronas e só completa os testes quando não restarem mais micro ou macrotasks na zona de teste.                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `fakeAsync`            | Executa o corpo de um teste \(`it`\) dentro de uma _zona de teste fakeAsync_ especial, permitindo um estilo de codificação com fluxo de controle linear.                                                                                                                                                                                                                                                                                                                                                                                                   |
| `tick`                 | Simula a passagem do tempo e a conclusão das atividades assíncronas pendentes, esvaziando as filas de _timer_ e de _micro-task_ dentro da _zona de teste fakeAsync_. O leitor curioso e dedicado pode gostar deste longo post de blog: ["_Tasks, microtasks, queues and schedules_"](https://jakearchibald.com/2015/tasks-microtasks-queues-and-schedules). Aceita um argumento opcional que avança o relógio virtual pelo número de milissegundos especificado, eliminando as atividades assíncronas agendadas dentro desse intervalo de tempo. |
| `discardPeriodicTasks` | Descarta as tarefas periódicas (por exemplo, `setInterval`) criadas dentro da Zone `fakeAsync`.                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `flushMicrotasks`      | Quando um teste `fakeAsync()` termina com _micro-tasks_ pendentes, como promises não resolvidas, o teste falha com uma mensagem de erro clara. <br /> Em geral, um teste deve esperar que as micro-tasks terminem. Quando micro-tasks pendentes são esperadas, chame `flushMicrotasks` para esvaziar a fila de _micro-task_ e evitar o erro.                                                                                                                                                                                                          |
