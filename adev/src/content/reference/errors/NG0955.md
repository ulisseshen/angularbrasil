# Expressão track resultou em chaves duplicadas para uma determinada coleção.

Uma expressão track especificada no loop `@for` resultou em chaves duplicadas para uma determinada coleção, por exemplo:

```angular-ts
@Component({
  template: `@for (item of items; track item.value) {
    {{ item.value }}
  }`,
})
class Test {
  items = [
    {key: 1, value: 'a'},
    {key: 2, value: 'b'},
    {key: 3, value: 'a'},
  ];
}
```

No exemplo fornecido, a expressão de tracking `item.value` encontrará duas chaves duplicadas `a` (nos índices 0 e 2).

Chaves duplicadas são problemáticas do ponto de vista de correção: como o loop `@for` não consegue identificar os itens de forma única, ele pode escolher nós DOM correspondentes a _outro_ item (com a mesma chave) ao realizar movimentações ou destruições no DOM.

Também há uma penalidade de performance associada a chaves duplicadas: internamente, o Angular precisa usar estruturas de dados mais sofisticadas e mais lentas ao iterar sobre coleções com chaves duplicadas.

## Corrigindo o erro {#fixing-the-error}

Altere a expressão de tracking para que ela identifique de forma única um item em uma coleção. No exemplo discutido, a expressão track correta usaria a propriedade única `key` (`item.key`):

```angular-ts
@Component({
  template: `@for (item of items; track item.key) {
    {{ item.value }}
  }`,
})
class Test {
  items = [
    {key: 1, value: 'a'},
    {key: 2, value: 'b'},
    {key: 3, value: 'a'},
  ];
}
```
