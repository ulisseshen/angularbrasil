# Seletor Shadow DOM inválido {#invalid-shadow-dom-selector}

O seletor de um component que usa `ViewEncapsulation.ShadowDom` não atende aos requisitos de nome de tag de elemento customizado.

Para que um nome de tag seja considerado um nome válido de elemento customizado, ele precisa:

- Estar em letras minúsculas.
- Conter um hífen.
- Começar com uma letra \(a-z\).

## Depurando o erro {#debugging-the-error}

Renomeie o seletor do seu component para que ele atenda aos requisitos.

**Antes:**

```ts
@Component({
  selector: 'comp',
  encapsulation: ViewEncapsulation.ShadowDom
…
})

```

**Depois:**

```ts
@Component({
  selector: 'app-comp',
  encapsulation: ViewEncapsulation.ShadowDom
…
})
```
