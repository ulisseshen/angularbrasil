# Atributo inválido

<docs-video src="https://www.youtube.com/embed/wfLkB3RsSJM"/>

Um atributo ou propriedade não pode ser resolvido durante a compilação.

Este erro surge ao tentar fazer binding para uma propriedade que não existe.
Qualquer property binding deve corresponder a:

- Uma propriedade nativa do elemento HTML, ou
- Uma propriedade `input()`/`@Input()` de um component ou directive aplicado ao elemento.

O erro de runtime correspondente é `NG0303: Can't bind to '${propName}' since it isn't a known property of '${tagName}'`.

## Depurando o erro {#debugging-the-error}

Consulte a documentação sobre a [sintaxe de binding](guide/templates) específica que você usou. Geralmente é um erro de digitação ou um import incorreto.
Também pode haver uma directive ausente com o seletor de propriedade 'name' ou um input ausente.
