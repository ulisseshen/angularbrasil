# Alvo de evento não suportado

O Angular reconhece apenas três valores de string como alvos globais de evento: `'window'`, `'document'` e `'body'`. Se você passar qualquer outro valor como alvo de string ao registrar um listener de evento global, o Angular não consegue resolvê-lo e lança este erro.

## Depurando o erro {#debugging-the-error}

Verifique se há um erro de digitação no nome do alvo usado com `@HostListener` ou `Renderer2.listen()`. Um pequeno erro como `'windw'` em vez de `'window'` já é suficiente para disparar este erro:

```angular-ts
@Component({
  selector: 'app-example',
  template: '<button>Click me</button>',
})
export class Example {
  @HostListener('windw:resize') // erro de digitação: deveria ser 'window'
  onResize() {}
}
```

O mesmo vale ao chamar `Renderer2.listen()` diretamente com uma string que o Angular não conhece:

```typescript
this.renderer.listen('global', 'click', handler); // 'global' não é suportado
```

## Corrigindo o erro {#fixing-the-error}

Corrija o alvo para uma das três strings suportadas, ou passe um elemento DOM real em vez de uma string:

```angular-ts
@Component({
  selector: 'app-example',
  template: '<button>Click me</button>',
})
export class Example {
  @HostListener('window:resize')
  onResize() {}
}
```

```typescript
// Use uma referência de elemento quando precisar apontar para algo mais específico
this.renderer.listen(this.elementRef.nativeElement, 'click', handler);
```
