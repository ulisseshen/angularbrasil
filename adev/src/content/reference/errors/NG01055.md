# Controle ausente para `formControlName` {#missing-control-for-formcontrolname}

Um `formControlName` no template aponta para um controle que o `FormGroup` não possui. A diretiva procura o controle pelo seu caminho e não encontra nada.

Isso pode acontecer quando o template e o form group são construídos a partir dos mesmos dados, mas usam filtros diferentes. Um item é renderizado no template, mas nunca recebeu um controle no form group, então o seu `formControlName` não tem nada ao que se vincular.

```angular-ts
@Component({
  template: `
    <form [formGroup]="form">
      <ng-container formGroupName="options">
        @for (id of visibleIds; track id) {
          <input [formControlName]="id" />
        }
      </ng-container>
    </form>
  `,
})
class App {
  // O template renderiza um input para os dois ids...
  visibleIds = [1, 2];
  // ...mas o form group só tem um controle para o id 1.
  form = new FormGroup({
    options: new FormGroup({
      1: new FormControl(''),
    }),
  });
}
```

## Depurando o erro {#debugging-the-error}

A mensagem de erro lista os controles que existem naquele nível, por exemplo:

```
Cannot find control with path: 'options -> 2'. Controls that do exist at this level: 1.
```

Compare-a com os nomes que o seu template vincula. Em seguida, adicione o controle ausente ao `FormGroup` ou deixe de renderizar o `formControlName` do item que não tem controle.
