# Avisos de performance em runtime {#runtime-performance-warnings}

### Imagens superdimensionadas {#oversized-images}

Quando as imagens são carregadas, o **tamanho intrínseco** do arquivo baixado é comparado com o tamanho real da imagem na página. O tamanho real é calculado usando o **tamanho renderizado** da imagem com o CSS aplicado, multiplicado pela [razão de pixels do dispositivo](https://web.dev/codelab-density-descriptors/#pixel-density). Se a imagem baixada for muito maior (mais de 1200px acima em qualquer dimensão), este aviso é disparado. Baixar imagens superdimensionadas pode deixar o carregamento da página mais lento e ter um efeito negativo nos [Core Web Vitals](https://web.dev/vitals/).

### Elemento LCP com lazy loading {#lazy-loaded-lcp-element}

O maior elemento de conteúdo de uma página durante o carregamento é considerado o "Elemento LCP", que se relaciona com o [Largest Contentful Paint](https://web.dev/lcp/), uma das Core Web Vitals. Aplicar lazy loading em um elemento LCP tem um forte efeito negativo na performance da página. Com essa estratégia, o browser precisa concluir os cálculos de layout para determinar se o elemento está na viewport antes de iniciar o download da imagem. Por isso, um aviso é disparado quando o Angular detecta que o elemento LCP recebeu o atributo `loading="lazy"`.

### Depurando o erro {#debugging-the-error}

Use a URL da imagem fornecida no aviso do console para encontrar o elemento `<img>` em questão.

### Formas de corrigir imagens superdimensionadas {#ways-to-fix-oversized-images}

- Use uma imagem de origem menor
- Adicione um [`srcset`](https://web.dev/learn/design/responsive-images/#responsive-images-with-srcset) se forem necessários múltiplos tamanhos para diferentes layouts.
- Mude para a diretiva de imagem integrada do Angular ([`NgOptimizedImage`](/api/common/NgOptimizedImage)), que gera [srcsets automaticamente](/guide/image-optimization#request-images-at-the-correct-size-with-automatic-srcset).

### Formas de corrigir elemento LCP com lazy loading {#ways-to-fix-lazy-loaded-lcp-element}

- Altere o atributo `loading` para outro valor, como `"eager"`.
- Mude para a diretiva de imagem integrada do Angular ([`NgOptimizedImage`](/api/common/NgOptimizedImage)), que permite [priorizar imagens LCP](/guide/image-optimization#mark-images-as-priority) com facilidade.

### Desativando avisos de performance de imagem {#disabling-image-performance-warnings}

Ambos os avisos podem ser desativados individualmente, para todo o site, usando um provider na raiz da sua aplicação:

```typescript
providers: [
  {
    provide: IMAGE_CONFIG,
    useValue: {
      disableImageSizeWarning: true,
      disableImageLazyLoadWarning: true
    }
  },
],
```
