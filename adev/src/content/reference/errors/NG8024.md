# Binding de host directive conflitante

Duas ou mais declarações de host directive expõem a **mesma input ou output com aliases diferentes**,
o que torna impossível para o Angular mesclar as instâncias duplicadas da host directive.

Este erro surge do [padrão de composição em diamante](guide/directives/directive-composition-api#host-directive-de-duplication):
duas directives declaram a mesma directive compartilhada em seus `hostDirectives`, mas cada uma expõe
um dos bindings dela com um nome de alias diferente.

```angular-ts
@Directive()
export class Shared {
  readonly value = input('');
}

@Directive({
  selector: '[dirA]',
  hostDirectives: [{directive: Shared, inputs: ['value: aliasA']}],
})
export class DirA {}

@Directive({
  selector: '[dirB]',
  hostDirectives: [{directive: Shared, inputs: ['value: aliasB']}], // alias diferente!
})
export class DirB {}

@Component({
  selector: 'app-root',
  // NG8024: Shared.value é exposta tanto como "aliasA" (via DirA) quanto como "aliasB" (via DirB).
  template: `<div dirA dirB></div>`,
  imports: [DirA, DirB],
})
export class AppComponent {}
```

## Depurando o erro {#debugging-the-error}

A mensagem de erro identifica a directive e a input ou output que está em conflito. Encontre todas as
declarações de `hostDirectives` que incluem essa directive compartilhada e inspecione os arrays `inputs` ou
`outputs` para o binding conflitante.

Para resolver o erro, escolha uma das abordagens a seguir:

- **Use o mesmo alias nos dois lugares.** As duas declarações de host directive devem expor o binding
  com o mesmo nome público.
- **Remova o alias de uma ou de ambas as declarações.** Se nenhuma das declarações precisa expor o
  binding para os consumidores, omita-o completamente dos arrays `inputs` ou `outputs`.

Veja [De-duplicação de host directives](guide/directives/directive-composition-api#host-directive-de-duplication)
para mais informações sobre como o Angular mescla host directives duplicadas e o que constitui um conflito.
