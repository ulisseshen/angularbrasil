# Valor de controle ausente

Este erro ocorre quando você chama `setValue` em um `FormGroup` ou `FormArray`, mas o valor passado não tem uma entrada para um dos controles registrados.

`setValue` é estrito: ele espera um valor para cada controle. Se você quiser atualizar apenas alguns controles, use `patchValue`.

## Depurando o erro {#debugging-the-error}

Verifique qual controle é citado na mensagem de erro e, em seguida, certifique-se de que o objeto de valor inclui esse controle.

Uma fonte comum deste erro é espalhar (spread) um objeto que não tem todas as chaves:

```typescript
const someValue = {first: 'Nancy'}; // 'last' está faltando

form.setValue({...someValue}); // lança NG01002
```

Isso pode acontecer se `someValue` vier de uma resposta de API, de uma atualização parcial de estado ou de um tipo que não corresponde totalmente à estrutura do formulário. Nesses casos, preencha explicitamente as chaves ausentes ou troque para `patchValue`.

### FormGroup

```typescript
const form = new FormGroup({
  first: new FormControl(''),
  last: new FormControl(''),
});

// 'last' não está no valor — lança NG01002
form.setValue({first: 'Nancy'});

// os dois controles estão cobertos — funciona normalmente
form.setValue({first: 'Nancy', last: 'Drew'});
```

### FormArray

```typescript
const formArray = new FormArray([new FormControl(''), new FormControl('')]);

// apenas um valor para dois controles — lança NG01002
formArray.setValue(['Nancy']);

// um valor por controle — funciona normalmente
formArray.setValue(['Nancy', 'Drew']);
```
