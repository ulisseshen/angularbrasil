# EnvironmentProviders em contexto incorreto

Este erro ocorre quando `EnvironmentProviders` são usados em um contexto que aceita apenas providers comuns, como o array `providers` de um component. Environment providers são projetados para configuração em toda a aplicação e só podem ser usados em environment injectors (como o injector raiz configurado em `bootstrapApplication` ou nas configurações de rotas).

## Cenários comuns {#common-scenarios}

### Usando `provideHttpClient()` nos providers de component {#using-providehttpclient-in-component-providers}

Funções como `provideHttpClient()` retornam `EnvironmentProviders`, que não podem ser usados no nível do component:

```ts
@Component({
  providers: [
    provideHttpClient(), // ERRO: EnvironmentProviders não podem ser usados aqui
  ],
})
export class UserProfile {}
```

### Usando `importProvidersFrom()` nos providers de component {#using-importprovidersfrom-in-component-providers}

A função `importProvidersFrom()` também retorna `EnvironmentProviders`:

```ts
@Component({
  providers: [
    importProvidersFrom(SomeModule), // ERRO: não pode ser usado para providers de component
  ],
})
export class DataView {}
```

## Depurando o erro {#debugging-the-error}

Mova os environment providers para um local apropriado:

### Para providers em nível de aplicação {#for-application-wide-providers}

Configure os environment providers em `bootstrapApplication`:

```ts
bootstrapApplication(App, {
  providers: [provideHttpClient(), importProvidersFrom(SomeModule)],
});
```

### Para providers específicos de rota {#for-route-specific-providers}

Use o array `providers` nas configurações de rotas:

```ts
const routes: Routes = [
  {
    path: 'admin',
    component: AdminView,
    providers: [provideHttpClient(withInterceptors([authInterceptor]))],
  },
];
```

### Para services em nível de component {#for-component-level-services}

Se você precisar de services com escopo de component, use providers comuns em vez de environment providers:

```ts
@Component({
  providers: [
    UserClient, // Provider comum - isto funciona
    {provide: API_URL, useValue: '/api'}, // Provider de valor - isto funciona
  ],
})
export class UserProfile {}
```

A mensagem de erro especifica qual provider causou o problema. Verifique se todos os itens do array `providers` do seu component são providers comuns, e não environment providers retornados por funções como `provideHttpClient()`, `provideRouter()` ou `importProvidersFrom()`.
