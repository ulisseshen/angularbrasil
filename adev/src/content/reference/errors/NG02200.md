# Iterable Differ ausente {#missing-iterable-differ}

`NgFor` não conseguiu encontrar um iterable differ para o valor passado. Certifique-se de que seja um iterable, como um `Array`.

## Depurando o erro {#debugging-the-error}

Ao usar ngFor em um template, você deve usar algum tipo de Iterable, como `Array` ou `Set`.
Se você está tentando iterar sobre as chaves de um objeto ou as entradas de um `Map`, você deve olhar para o [KeyValue pipe](/api/common/KeyValuePipe) em vez disso.
