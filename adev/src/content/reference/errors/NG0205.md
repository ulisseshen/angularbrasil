# Injector já foi destruído {#injector-has-already-been-destroyed}

Este erro ocorre quando você tenta recuperar um service de um injector que já foi destruído. Isso normalmente acontece quando o código tenta acessar dependências depois que um component, uma diretiva ou um módulo já foi destruído.

## Cenários comuns {#common-scenarios}

### Acessando services em callbacks após a destruição {#accessing-services-in-callbacks-after-destruction}

Quando um component é destruído, seu injector também é destruído. Se um callback assíncrono tentar acessar services mais tarde, este erro ocorre:

```ts
@Component(/* ... */)
export class UserProfile implements OnInit {
  private userClient = inject(UserClient);

  ngOnInit() {
    setTimeout(() => {
      // ERRO: se o component foi destruído antes de o timeout disparar,
      // o injector não está mais disponível
      this.userClient.fetchData();
    }, 5000);
  }
}
```

### Acessando services após cancelar a inscrição {#accessing-services-after-unsubscribing}

Problemas semelhantes ocorrem com observables se a limpeza acontecer na ordem errada:

```ts
@Component(/* ... */)
export class DataView implements OnDestroy {
  private dataStore = inject(DataStore);

  ngOnDestroy() {
    // Problemático: tentando usar o injector durante a destruição,
    // depois que outras limpezas podem já ter ocorrido
    this.dataStore.cleanup();
  }
}
```

## Depurando o erro {#debugging-the-error}

Para corrigir este erro:

1. **Verifique as operações assíncronas** — Garanta que callbacks, promises e inscrições sejam cancelados quando o component for destruído. Use `takeUntilDestroyed()` ou `DestroyRef` para a limpeza.

2. **Capture as dependências cedo** — Armazene referências aos services em campos da classe, em vez de acessar o injector dentro de callbacks.

3. **Proteja contra o estado destruído** — Para operações que podem sobreviver ao component, verifique se o component ainda está ativo antes de acessar os services.

```ts
@Component(/* ... */)
export class UserProfile implements OnInit {
  private destroyRef = inject(DestroyRef);
  private userClient = inject(UserClient);

  ngOnInit() {
    // Use takeUntilDestroyed para cancelar automaticamente quando for destruído
    interval(5000)
      .pipe(takeUntilDestroyed(this.destroyRef))
      .subscribe(() => {
        this.userClient.fetchData();
      });
  }
}
```

O stack trace indica onde o injector destruído foi acessado. Trabalhe de trás para frente para identificar a operação assíncrona que sobreviveu ao seu component.
