# `inject()` deve ser chamado de um contexto de injeção

Você vê este erro quando tenta usar a função [`inject`](api/core/inject) fora do [contexto de injeção](guide/di/dependency-injection-context) permitido. O contexto de injeção está disponível durante a criação e a inicialização da classe. Ele também está disponível para funções usadas com `runInInjectionContext`.

Na prática, as chamadas a `inject()` são permitidas em um constructor, em um parâmetro de constructor e em um inicializador de campo:

```typescript
@Service()
export class Car {
  radio: Radio | undefined;

  // OK: inicializador de campo
  spareTyre = inject(Tyre);

  constructor() {
    // OK: corpo do constructor
    this.radio = inject(Radio);
  }
}
```

Também é válido chamar [`inject`](api/core/inject) a partir de uma factory de provider:

```typescript
providers: [
  {
    provide: Car,
    useFactory: () => {
      // OK: uma factory de classe
      const engine = inject(Engine);
      return new Car(engine);
    },
  },
];
```

Chamadas à função [`inject`](api/core/inject) fora da criação da classe ou de `runInInjectionContext` resultarão em erro. Mais especificamente, chamadas a `inject()` não são permitidas depois que uma instância da classe foi criada, em métodos (incluindo lifecycle hooks):

```typescript
@Component({ ... })
export class Car {
  ngOnInit() {
    // ERRO: tarde demais, a instância do component já foi criada
    const engine = inject(Engine);
    engine.start();
  }
}
```

## Depurando o erro {#debugging-the-error}

Trabalhe de trás para frente a partir do stack trace do erro para identificar o lugar onde está a chamada não permitida a `inject()`.

Para corrigir o erro, mova a chamada a [`inject`](api/core/inject) para um lugar permitido (geralmente o constructor de uma classe ou um inicializador de campo).

NOTE: Se você estiver executando em um contexto de teste, `TestBed.runInInjectionContext` fará com que `inject()` funcione.

```typescript
TestBed.runInInjectionContext(() => {
  // ...
});
```
