# Corpo da resposta do fetch excede o limite configurado {#fetch-response-body-exceeds-the-configured-limit}

O Angular gera este erro quando o `HttpClient` usa o backend fetch durante a renderização no servidor (SSR) e os bytes armazenados em buffer para o corpo de uma resposta excedem o limite `maxResponseBodySize` configurado. Por padrão, o Angular limita cada corpo de resposta armazenado em buffer a 1 MB, para evitar que o servidor armazene em buffer respostas muito grandes de forma inesperada durante a renderização.

## Corrigindo o erro {#fixing-the-error}

Defina `maxResponseBodySize` nas opções de `provideServerRendering` para aumentar o limite:

```ts
import {provideServerRendering, withRoutes} from '@angular/ssr';
import {ApplicationConfig} from '@angular/core';
import {serverRoutes} from './app.routes.server';

const serverConfig: ApplicationConfig = {
  providers: [
    provideServerRendering(
      {
        maxResponseBodySize: 5 * 1024 * 1024, // 5MB
      },
      withRoutes(serverRoutes),
    ),
  ],
};
```

`maxResponseBodySize` configura o número máximo de bytes do corpo da resposta que o Angular armazena em buffer para cada requisição `HttpClient` feita no servidor que usa o backend fetch. O valor é configurado em bytes e se aplica globalmente.

IMPORTANT: Mantenha este limite o menor possível dentro do que a sua aplicação permite. Aumentá-lo permite que requisições do lado do servidor armazenem em buffer corpos de resposta maiores, o que pode aumentar o uso de memória e o risco de negação de serviço (denial-of-service). Prefira mover downloads grandes para fora da renderização no servidor.

## Depurando o erro {#debugging-the-error}

A mensagem de erro inclui o limite `maxResponseBodySize` configurado, em bytes. Para identificar qual requisição HTTP está retornando uma resposta grande, verifique os logs de rede ou o console do servidor SSR para a URL da requisição que falhou.

Se a resposta grande é necessária apenas no cliente e não é necessária para a renderização no servidor, você pode desativar o transfer cache para essa requisição específica:

```ts
httpClient.get('/api/large-data', {transferCache: false});
```
