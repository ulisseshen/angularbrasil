# Valor inválido em binding de propriedade de estilo

O Angular detectou um valor com um tipo não suportado em um binding de propriedade de estilo. Isso pode ocorrer em um binding individual, como `[style.width]`, ou em uma propriedade de um mapa `[style]`.

Os valores de propriedades de estilo aceitam strings, números, objetos `SafeValue` de estilo, `null` e `undefined`. Outros valores, incluindo objetos `SafeValue` criados para um contexto de segurança que não seja de estilo, produzem este aviso no modo de desenvolvimento.

Por exemplo, o binding a seguir passa um booleano em vez de um valor CSS:

```angular-html
<div [style.display]="isVisible"></div>
```

## Depurando o erro {#debugging-the-error}

Use o nome da propriedade e o valor da mensagem de erro para localizar o binding. Converta o valor para uma string ou número CSS válido, ou use `null` ou `undefined` para remover o estilo.

Ao usar um sufixo de unidade como `[style.width.px]`, faça o binding apenas da parte numérica do valor:

```angular-html
<div [style.width.px]="width"></div>
```

Não passe para um binding de propriedade de estilo um `SafeValue` criado para outro contexto de segurança, como HTML confiável.
