# Nenhum provider encontrado {#no-provider-found}

<docs-video src="https://www.youtube.com/embed/lAlOryf1-WU"/>

Você vê este erro quando tenta injetar um service, mas não declarou um provider correspondente. Um provider é um mapeamento que fornece um valor que você pode injetar no constructor de uma classe da sua aplicação.

Leia mais sobre providers no nosso [guia de Injeção de Dependência](guide/di).

## Depurando o erro {#debugging-the-error}

Trabalhe de trás para frente a partir do objeto em que o erro afirma que um provider está faltando: `No provider for <token> found`. Isso é lançado com frequência em services que exigem providers inexistentes.

Para corrigir o erro, garanta que seu service esteja registrado na lista de providers de um `NgModule` ou tenha o decorator `@Service` no topo.

A solução mais comum é adicionar um provider no `@Service`:

```ts
@Service()
```
