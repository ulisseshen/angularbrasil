# Bindings inseguros em um elemento {#unsafe-bindings-on-an-element}

Você verá este erro quando o Angular detectar um property binding ou um attribute binding em um atributo sensível à segurança.
O Angular exige que esses atributos sejam definidos como atributos estáticos, para que os valores sejam definidos quando o elemento é criado
e permaneçam os mesmos durante todo o seu ciclo de vida. A mensagem de erro informa o nome do atributo e do elemento.

Isso se aplica a:

- atributos de `<iframe>` que configuram o seu modelo de segurança: `sandbox`, `allow`, `allowFullscreen`, `referrerPolicy`, `csp`,
  `fetchPriority` e `credentialless`. Eles devem ser aplicados antes dos atributos `src` ou `srcdoc`.
- atributos de animação SVG que poderiam alterar o `href` de outro elemento, como `attributeName` em `<animate>` e `<set>`.

Por exemplo, o erro é lançado quando um property binding é usado:

```angular-html
<iframe [sandbox]="'allow-scripts'" src="..."></iframe>
```

ou quando é um attribute binding:

```angular-html
<iframe [attr.sandbox]="'allow-scripts'" src="..."></iframe>
```

Além disso, o erro é lançado quando um padrão semelhante é usado em host bindings de uma Directive:

```typescript
@Directive({
  selector: 'iframe',
  host: {
    '[sandbox]': `'allow-scripts'`,
    '[attr.sandbox]': `'allow-scripts'`,
  },
})
class IframeDirective {}
```

## Depurando o erro {#debugging-the-error}

A mensagem de erro inclui o nome do component com o template onde
está localizado um elemento com bindings inseguros.

A solução recomendada é usar os atributos mencionados como estáticos, por exemplo:

```angular-html
<iframe sandbox="allow-scripts" src="..."></iframe>
```

Se você precisar de valores diferentes para esses atributos (dependendo de várias condições),
pode usar os blocos de controle de fluxo `@if` ou `@switch` para renderizar condicionalmente o elemento `<iframe>` apropriado:

```angular-html
@if (someConditionA) {
  <iframe sandbox="allow-scripts" src="..."></iframe>
} @else if (someConditionB) {
  <iframe sandbox="allow-forms" src="..."></iframe>
} @else {
  <iframe sandbox="allow-popups" src="..."></iframe>
}
```
