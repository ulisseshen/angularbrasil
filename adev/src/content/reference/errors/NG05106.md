# Nó de referência para inserção não encontrado {#insertion-reference-node-not-found}

O Angular lançou este erro porque tentou inserir um nó DOM ao lado de outro nó que ele estava rastreando, e esse nó não está mais onde o Angular espera que esteja.

O Angular mantém o registro dos nós DOM que renderiza para saber onde inserir, mover ou remover elementos depois, por exemplo quando um bloco `@for` é renderizado novamente. Se algo fora do Angular altera essa parte do DOM (remove um nó, move-o para outro lugar), o registro interno do Angular fica desatualizado. Na próxima vez que ele tentar inserir ao lado desse nó, você verá este erro, em vez de um `NotFoundError` nativo e confuso.

Isso pode acontecer por causa de:

- Código da aplicação que manipula o DOM diretamente (`ElementRef.nativeElement`, `document.querySelector`, `innerHTML` etc.) em vez de usar o Angular.
- Uma extensão do browser interferindo na página, como uma ferramenta de tradução, um corretor gramatical ou um gerenciador de senhas.
- Um caso extremo no próprio Angular, em código que reordena ou renderiza views condicionalmente (`@for`, `@if`, views criadas dinamicamente).

O exemplo a seguir dispara o erro:

```angular-ts
@Component({
  selector: 'app-example',
  template: `@if (show) {
    <span>{{ text }}</span>
  }`,
})
export class Example {
  show = true;
  text = 'hello';
  hostElement = inject(ElementRef).nativeElement;

  ngAfterViewInit() {
    // Remover este nó pelas costas do Angular é o que causa o erro.
    this.hostElement.querySelector('span').remove();
  }
}
```

## Depurando o erro {#debugging-the-error}

A mensagem de erro informa qual nó o Angular esperava encontrar, então comece por ela.

- Procure no código deste component (ou de um pai) algo que manipule o DOM diretamente em vez de usar as APIs do Angular, e troque por essas APIs.
- Se o erro aparece somente para alguns usuários, ou se você consegue reproduzi-lo localmente com uma extensão instalada, tente uma janela anônima com as extensões desativadas.
- Se ele acontece de forma consistente na mesma rota, para muitos usuários diferentes, provavelmente não é uma extensão (que varia por usuário). Procure algo determinístico nessa página, como um `@for`/`@if` que reordena ou remove conteúdo de forma incomum, ou um widget de terceiros incorporado nela.
- Se nada do que foi dito explicar o problema, abra uma issue com uma reprodução do erro.
