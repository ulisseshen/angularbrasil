# NgModel em component filho não consegue alcançar o formulário pai {#ngmodel-in-child-component-cannot-reach-parent-form}

Este aviso é emitido quando `ngModel` (ou qualquer controle de formulário orientado a template) está colocado dentro
de um component filho cujo component pai hospeda uma diretiva de formulário (`NgForm` ou
`FormGroupDirective`), mas o controle não consegue se registrar nesse formulário.

A causa raiz é que o `NgModel` injeta `ControlContainer` com `@Host()`, o que impede o
injector de atravessar os limites do component. A diretiva de formulário no template do component pai
fica invisível para o `NgModel` no template do filho.

Como resultado, os controles do filho agem silenciosamente como independentes: eles não participam do
valor, da validade nem do estado de envio do formulário pai.

## Corrigindo o aviso {#fixing-the-warning}

### Opção 1: conecte o `ControlContainer` com `viewProviders` {#option-1-bridge-the-controlcontainer-with-viewproviders}

Adicione `viewProviders` ao component filho para que ele reexporte o formulário pai para dentro da sua própria view.
Use a mesma classe que o aviso cita: `NgForm` para formulários orientados a template (`<form>`), ou
`FormGroupDirective` para formulários reativos (`[formGroup]`):

```angular-ts
// O pai usa um formulário orientado a template: <form> ... <app-child> </form>
import {ControlContainer, NgForm} from '@angular/forms';
import {Component} from '@angular/core';

@Component({
  selector: 'app-child',
  template: `<input name="email" [(ngModel)]="email" />`,
  viewProviders: [{provide: ControlContainer, useExisting: NgForm}],
})
export class Child {
  email = '';
}
```

```angular-ts
// O pai usa um formulário reativo: <div [formGroup]="myGroup"> ... <app-child> </div>
import {ControlContainer, FormGroupDirective} from '@angular/forms';
import {Component} from '@angular/core';

@Component({
  selector: 'app-child',
  template: `<input name="email" [(ngModel)]="email" />`,
  viewProviders: [{provide: ControlContainer, useExisting: FormGroupDirective}],
})
export class Child {
  email = '';
}
```

Depois disso, o formulário pai vê e valida os controles do filho normalmente.

### Opção 2: marque o controle como standalone {#option-2-mark-the-control-as-standalone}

Se os controles do filho devem realmente ser independentes do formulário pai, faça a exclusão explicitamente:

```html
<input name="email" [(ngModel)]="email" [ngModelOptions]="{standalone: true}" />
```

## Depurando o aviso {#debugging-the-warning}

A mensagem de aviso inclui o código de erro `NG01354`. Use a call stack para localizar qual
`ngModel` o disparou. Verifique se o component que possui a tag `<form>` é o mesmo
component que possui a entrada `ngModel`. Se forem diferentes, aplique uma das opções acima.
