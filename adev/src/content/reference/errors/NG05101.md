# Nenhum plugin de event manager encontrado para o evento

Este erro ocorre quando o Angular tenta configurar um listener para um evento, mas nenhum dos plugins de event manager registrados reconhece o nome do evento.

## Depurando o erro {#debugging-the-error}

A mensagem de erro inclui o nome do evento não reconhecido. Ele ocorre somente quando nenhum plugin registrado oferece suporte ao evento, por exemplo quando um `EventManager` é criado com uma lista de plugins customizada que não inclui o `DomEventsPlugin`, como em testes unitários ou configurações customizadas.

Se o nome do evento é intencional e pertence a um plugin de terceiros (por exemplo, um evento de gesto do Hammer.js), certifique-se de que o plugin está sendo fornecido pelo token `EVENT_MANAGER_PLUGINS`:

```typescript
import {ApplicationConfig} from '@angular/core';
import {EVENT_MANAGER_PLUGINS} from '@angular/platform-browser';

export const appConfig: ApplicationConfig = {
  providers: [{provide: EVENT_MANAGER_PLUGINS, useClass: MyCustomPlugin, multi: true}],
};
```
