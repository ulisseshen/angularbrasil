# Control flow impedindo a projeção de conteúdo {#control-flow-preventing-content-projection}

Um elemento ou `<ng-template>` dentro de um bloco de control flow seria projetado em um slot específico de `<ng-content>`, mas não é, porque o bloco tem mais de um node raiz.

```angular-ts
import {Component} from '@angular/core';

@Component({
  selector: 'app-card',
  template: `
    <ng-content select="[card-title]" />
    <ng-content />
  `,
})
class Card {}

@Component({
  imports: [Card],
  // NG8011: <h2 card-title> não é projetado no slot "[card-title]" porque o @if
  // tem dois nodes raiz (o h2 e o p).
  template: `
    <app-card>
      @if (showTitle) {
        <h2 card-title>Title</h2>
        <p>Subtitle</p>
      }
    </app-card>
  `,
})
class MyComponent {
  showTitle = true;
}
```

## Depurando o erro {#debugging-the-error}

Os blocos de control flow emulam o comportamento de projeção de conteúdo de `*ngIf` e `*ngFor`, que projetam o elemento ao qual são aplicados.
Isso só funciona se o bloco tiver um único node raiz.
Quando o bloco tem mais de um node raiz, o Angular não consegue usar o elemento para escolher um slot, então `<h2 card-title>` acaba no slot padrão `<ng-content />` de `Card`, em vez do slot `[card-title]`.

Texto também conta como node raiz, então uma linha de texto solta ao lado do elemento projetado causa o mesmo problema, a menos que o component que contém o bloco defina `preserveWhitespaces: true`, caso em que os espaços em branco também contam.

Para resolver o erro, escolha uma das abordagens a seguir:

- **Envolva o conteúdo em um `<ng-container>` que use [`ngProjectAs`](guide/components/content-projection#aliasing-content-for-projection)** para corresponder ao seletor do slot. Tudo dentro do container é projetado nesse slot.

  ```angular-ts
  @Component({
    imports: [Card],
    template: `
      <app-card>
        @if (showTitle) {
          <ng-container ngProjectAs="[card-title]">
            <h2>Title</h2>
            <p>Subtitle</p>
          </ng-container>
        }
      </app-card>
    `,
  })
  class MyComponent {
    showTitle = true;
  }
  ```

- **Divida o conteúdo em vários blocos**, de modo que cada um tenha um único node projetável na raiz.

  ```angular-ts
  @Component({
    imports: [Card],
    template: `
      <app-card>
        @if (showTitle) {
          <h2 card-title>Title</h2>
        }
        @if (showTitle) {
          <p>Subtitle</p>
        }
      </app-card>
    `,
  })
  class MyComponent {
    showTitle = true;
  }
  ```
