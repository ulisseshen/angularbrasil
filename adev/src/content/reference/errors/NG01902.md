# Campo órfão em signal forms {#orphan-field-in-signal-forms}

Este erro indica que uma instância de `Field` não está mais conectada à estrutura atual do model.
Os signal forms do Angular lançam `NG01902` quando um caminho de campo que existia antes não pode mais ser resolvido como a mesma propriedade no objeto pai.

Um gatilho comum é definir, sem querer, o valor de um campo como `undefined`.
Em signal forms, `undefined` significa "o campo não existe", então um campo existente pode ficar órfão.

## Por que isso acontece {#why-this-happens}

Os signal forms mantêm as instâncias de campo sincronizadas com o formato do seu model.
Se o código ainda referencia uma instância de campo antiga depois que o formato do model mudou, o Angular detecta a divergência e lança este erro.

Isso pode acontecer quando:

- uma propriedade é removida do objeto do model
- uma propriedade passa a ser `undefined` em vez de permanecer presente
- o código mantém uma referência de campo desatualizada entre atualizações estruturais

## Como corrigir {#how-to-fix-it}

- Evite escrever `undefined` nos campos do model. Use `null` ou outro valor explícito quando o campo ainda deve existir.
- Mantenha o formato do model estável enquanto um campo estiver em uso.
- Releia os campos da árvore de formulário atual após atualizações estruturais, em vez de reutilizar referências desatualizadas.

Para orientações sobre o design do model, veja [Evite `undefined`](/guide/forms/signals/model-design#avoid-undefined).
