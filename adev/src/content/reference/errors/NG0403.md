# NgModule usado no bootstrap não especifica qual component inicializar

Este erro significa que um NgModule usado para fazer o bootstrap de uma aplicação está sem informações-chave para que o Angular prossiga com o processo de bootstrap.

O erro acontece quando a propriedade `bootstrap` do NgModule está ausente (ou é um array vazio) na anotação `@NgModule` e não há um lifecycle hook `ngDoBootstrap` definido nessa classe NgModule.

Mais informações sobre o processo de bootstrap podem ser encontradas [neste guia](guide/ngmodules/overview).

Os exemplos a seguir irão disparar o erro.

```typescript
@NgModule({
  declarations: [App],
  imports: [BrowserModule, AppRoutingModule],
  providers: [],
})
export class AppModule {}

// O `AppModule` é usado para o bootstrap, mas o campo `@NgModule.bootstrap` está ausente.
platformBrowser().bootstrapModule(AppModule);
```

```typescript
@NgModule({
  declarations: [App],
  imports: [BrowserModule, AppRoutingModule],
  providers: [],
  bootstrap: [],
})
export class AppModule {}

// O `AppModule` é usado para o bootstrap, mas o campo `@NgModule.bootstrap` contém um array vazio.
platformBrowser().bootstrapModule(AppModule);
```

## Depurando o erro {#debugging-the-error}

Certifique-se de que o NgModule usado para o bootstrap está configurado corretamente:

- ou a propriedade `bootstrap` existe (e contém um array não vazio) na anotação `@NgModule`
- ou o método `ngDoBootstrap` existe na classe NgModule
