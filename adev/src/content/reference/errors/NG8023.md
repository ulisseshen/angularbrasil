# Vários components correspondem ao mesmo elemento {#multiple-components-match-same-element}

Dois ou mais [components](guide/components) no escopo de compilação correspondem ao mesmo elemento em um template.
Como o Angular só pode associar um component a um determinado elemento, os seletores precisam ser suficientemente únicos para evitar ambiguidade.

NOTE: Este é o equivalente, em tempo de build, do erro de runtime [NG0300: Colisão de Seletor](errors/NG0300). Detectar isso em tempo de compilação faz o erro aparecer imediatamente.

```angular-ts
import {Component} from '@angular/core';

@Component({
  selector: '[stroked-button]',
  template: '',
})
export class StrokedBtn {}

@Component({
  selector: '[raised-button]',
  template: '',
})
export class RaisedBtn {}

@Component({
  selector: 'app-root',
  // NG8023: StrokedBtn e RaisedBtn correspondem ambos a este elemento.
  template: `<button stroked-button raised-button></button>`,
  imports: [StrokedBtn, RaisedBtn],
})
export class App {}
```

## Depurando o erro {#debugging-the-error}

Use o nome do elemento da mensagem de erro para procurar lugares onde você está usando a mesma declaração de seletor na sua base de código:

```ts

@Component({
  selector: 'YOUR_STRING',
…
})

```

Certifique-se de que cada component tem um seletor CSS único. Isso garantirá que o Angular renderize o component que você espera.

Se você estiver tendo problemas para encontrar múltiplos components com este nome de tag de seletor, verifique os components de bibliotecas de components importadas, como o Angular Material. Certifique-se de seguir as [boas práticas](style-guide#choosing-component-selectors) para os seus seletores, para evitar colisões.
