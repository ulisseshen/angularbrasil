# Referência do CLI

| Comando                            | Alias      | Descrição                                                                                                          |
| :--------------------------------- | :--------- | :----------------------------------------------------------------------------------------------------------------- |
| [`add`](cli/add)                   |            | Adiciona suporte para uma biblioteca externa ao seu projeto.                                                       |
| [`analytics`](cli/analytics)       |            | Configura a coleta de métricas de uso do Angular CLI.                                                              |
| [`build`](cli/build)               | `b`        | Compila uma aplicação ou biblioteca Angular em um diretório de saída chamado dist/, no caminho de saída fornecido. |
| [`cache`](cli/cache)               |            | Configura o cache persistente em disco e recupera estatísticas de cache.                                           |
| [`completion`](cli/completion)     |            | Configura o autocompletar do Angular CLI para o seu terminal.                                                      |
| [`config`](cli/config)             |            | Recupera ou define valores de configuração do Angular no arquivo angular.json do workspace.                        |
| [`deploy`](cli/deploy)             |            | Invoca o builder de deploy para um projeto especificado ou para o projeto padrão do workspace.                     |
| [`e2e`](cli/e2e)                   | `e`        | Constrói e serve uma aplicação Angular e, em seguida, executa testes end-to-end.                                   |
| [`extract-i18n`](cli/extract-i18n) |            | Extrai mensagens i18n do código-fonte.                                                                             |
| [`generate`](cli/generate)         | `g`        | Gera e/ou modifica arquivos com base em um schematic.                                                              |
| [`lint`](cli/lint)                 |            | Executa ferramentas de lint no código da aplicação Angular em uma determinada pasta de projeto.                    |
| [`new`](cli/new)                   | `n`        | Cria um novo workspace Angular.                                                                                    |
| [`run`](cli/run)                   |            | Executa um target do Architect com uma configuração de builder personalizada opcional definida no seu projeto.     |
| [`serve`](cli/serve)               | `s`, `dev` | Constrói e serve sua aplicação, reconstruindo-a quando os arquivos mudam.                                          |
| [`test`](cli/test)                 | `t`        | Executa testes unitários em um projeto.                                                                            |
| [`update`](cli/update)             |            | Atualiza seu workspace e suas dependências. Veja o [Guia de atualização](/update-guide).                           |
| [`version`](cli/version)           | `v`        | Exibe a versão do Angular CLI.                                                                                     |
