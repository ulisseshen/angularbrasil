# Declaração `@let` não utilizada

Este diagnóstico detecta declarações `@let` cujo valor nunca é lido no template.

```angular-ts
import {Component} from '@angular/core';

@Component({
  template: `
    @let fullName = user.firstName + ' ' + user.lastName;
    <h1>Welcome</h1>
  `,
})
class MyComponent {
  user = {firstName: 'Ada', lastName: 'Lovelace'};
}
```

## O que há de errado com isso? {#whats-wrong-with-that}

Um `@let` não utilizado geralmente é resquício de uma refatoração ou indica um lugar onde o valor deveria ter sido usado.
O Angular ainda avalia a expressão de um `@let` não utilizado sempre que o template é atualizado. Por exemplo, uma chamada de função na expressão ainda é executada.

## O que devo fazer em vez disso? {#what-should-i-do-instead}

Use a declaração ou remova-a:

```angular-ts {prefer, header: "use a declaração"}
@Component({
  template: `
    @let fullName = user.firstName + ' ' + user.lastName;
    <h1>Welcome, {{ fullName }}</h1>
  `,
})
class MyComponent {
  user = {firstName: 'Ada', lastName: 'Lovelace'};
}
```

```angular-ts {prefer, header: "remova a declaração"}
@Component({
  template: `<h1>Welcome</h1>`,
})
class MyComponent {}
```

## E se eu não puder evitar isso? {#what-if-i-cant-avoid-this}

Este diagnóstico pode ser desativado editando o arquivo `tsconfig.json` do projeto:

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "unusedLetDeclaration": "suppress"
      }
    }
  }
}
```

Veja [configuração de diagnósticos estendidos](extended-diagnostics#configuration) para mais informações.
