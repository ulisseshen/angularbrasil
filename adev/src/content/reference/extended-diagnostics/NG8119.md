# Propriedade CSS numérica requer uma unidade

Este diagnóstico detecta quando um valor numérico é vinculado a uma propriedade de comprimento CSS que requer uma unidade CSS para ter qualquer efeito.

```angular-html
<!-- Binding de um número puro – não tem efeito visual -->
<div [style.width]="500"></div>

<!-- Binding de uma string numérica – também não tem efeito -->
<div [style.padding]="'20'"></div>
```

## O que há de errado com isso? {#whats-wrong-with-that}

Propriedades de comprimento CSS como `width`, `height`, `margin`, `padding`, `font-size` e muitas outras exigem uma unidade (por exemplo, `px`, `em`, `%`, `rem`) para terem efeito. Fazer binding de um número puro como `500` define a propriedade como a string `"500"`, que os navegadores tratam como um valor inválido e ignoram silenciosamente. O elemento é renderizado como se o estilo nunca tivesse sido aplicado.

## O que devo fazer em vez disso? {#what-should-i-do-instead}

Existem duas formas idiomáticas de fazer binding de um valor de comprimento com unidade em templates do Angular.

### Use o atalho com sufixo de unidade {#use-the-unit-suffix-shorthand}

Adicione a unidade desejada diretamente ao nome do binding usando a sintaxe de sufixo `.unit`:

```angular-html
<div [style.width.px]="500"></div>
<div [style.padding.rem]="1.5"></div>
<div [style.margin-top.%]="10"></div>
```

### Faça binding de uma string que já inclui a unidade {#bind-a-string-that-already-includes-the-unit}

Se precisar compor o valor dinamicamente, faça binding de uma string de valor CSS completa:

```angular-html
<div [style.width]="'500px'"></div>
<div [style.padding]="myPadding + 'px'"></div>
```

## Requisitos de configuração {#configuration-requirements}

[`strictTemplates`](tools/cli/template-typecheck#strict-mode) deve estar habilitado para que qualquer diagnóstico estendido seja emitido.
`numericCssPropertyRequiresUnit` não tem requisitos adicionais além de `strictTemplates`.

## E se eu não puder evitar isso? {#what-if-i-cant-avoid-this}

Este diagnóstico pode ser desativado editando o arquivo `tsconfig.json` do projeto:

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "numericCssPropertyRequiresUnit": "suppress"
      }
    }
  }
}
```

Veja [configuração de diagnósticos estendidos](extended-diagnostics#configuration) para mais informações.
